# H3video-2k Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add H3video-2k from PixelleLabs as an independent async video route with a separate CredentialVault API key.

**Architecture:** Add a dedicated adapter and built-in plugin manifest. The adapter maps canonical video references to PixelleLabs' `/v1/videos` create/poll contract and keeps provider credentials server-side. Capabilities expose text-to-video, image-to-video, image-reference, and all-reference only; first/last-frame is excluded.

**Tech Stack:** TypeScript, Vitest, AI Gateway plugin manifests, CredentialVault, Docker Compose v2.
