# 视频节点视觉还原重做规格

状态：待用户书面确认  
日期：2026-07-17  
适用范围：TapFlow v2 画布中的视频节点 Composer、参数面板、运镜库、调色盘与相关中文文案

## 1. 背景与结论

当前视频节点已经具备数据契约、模型能力校正、草稿持久化、生成前门禁和 23 个稳定运镜 ID，但上线视觉没有兑现此前确认的参考方案：

- 可见界面与无障碍文案混用中英文。
- 运镜预览采用抽象几何演示场景，无法直观看出镜头对人物和环境的真实影响。
- 参数面板沿用通用下拉表单，缺少比例图形、分段选择和清晰的参数层级。
- 调色盘缺少“人物、场景、道具、风格”等语义分组，交互接近工程配置页。
- Composer 的信息结构虽然功能齐全，但与确认的 DramaClaw/LibTV 创作工作台在视觉密度、层级和展开方式上差距明显。

本次不是局部换肤，而是在保留现有数据、模型和生成安全边界的前提下，重做视频创作 UI。DramaClaw 仅作为交互结构与视觉密度参考；运镜预览使用已取得商业授权的原始 MP4，不复制其代码、品牌或商标。

## 2. 目标与非目标

### 2.1 目标

1. 创作者可见界面全部使用简体中文，包括按钮、标题、标签页、空状态、提示、无障碍名称和错误信息。模型正式产品名、分辨率和宽高比等行业标识可保留原文。
2. 主 Composer 的信息结构、参数展开方式、运镜库和调色盘达到已确认参考图的视觉层级与操作效率。
3. 运镜卡使用已取得商业授权的 DramaClaw 原始 MP4 展示不同镜头运动，使用户无需阅读说明即可比较运动方向和景别变化。
4. 参数面板用图形卡、分段控件、滑杆和数字输入表达参数，避免通用下拉表单堆叠。
5. 每个主要界面都通过真实浏览器截图验收，不再只依赖 DOM、单元测试或功能 smoke。

### 2.2 非目标

- 不复制 DramaClaw 的代码、品牌、角色形象或商标；仅使用已取得商业授权并随版本清单发布的 23 个原始 MP4。
- 不修改已稳定的 `params.videoGeneration`、运镜稳定 ID、模型目录、计费或 worker/provider 协议。
- 不在本期补充没有真实数据路径的角色库、特效库或标记功能。
- 不接入真实视频模型；生成前门禁仍保持 fail-closed。

## 3. 视觉基线

整体采用安静的深色专业创作工具风格：深灰画布、炭黑工作台、1px 低对比描边、白色主文字、灰色辅助文字，以现有天蓝色作为唯一主操作强调色。避免玻璃拟态、渐变球、过度发光和装饰性大圆角。

关键尺寸：

- Composer 桌面宽度：`clamp(720px, 58vw, 1040px)`，窄屏使用视口宽度减 24px。
- Composer 圆角：12px；内部浮层圆角：10px；运镜卡圆角：8px。
- 主操作高度：40px；紧凑图标按钮：36px；正文：13-14px；辅助文字：11-12px。
- 运镜库桌面四列，卡片固定 16:9；1024px 三列；移动端两列。
- 主要浮层不使用一层套一层的装饰卡片，只保留必要的工具表面和重复项卡片。

## 4. 全中文规范

所有视频节点组件使用集中式中文词典或常量，禁止在 JSX 中新增英文界面文案。首轮必须替换：

| 当前文案 | 中文文案 |
| --- | --- |
| Subject | 人物 |
| Scene | 场景 |
| Prop | 道具 |
| Style | 风格 |
| Camera motion library | 运镜库 |
| All | 全部运镜 |
| Favorites | 我的收藏 |
| My motions | 我的运镜 |
| Search motions | 搜索运镜 |
| Clear | 清除 |
| Use | 使用 |
| Auto | 自动 |
| Choose video model | 选择模型 |
| Video parameters | 视频参数 |

测试必须扫描视频组件渲染结果，拒绝上述英文残留、乱码字符和错误编码文本。`Seedance`、`Kling` 等正式模型名不翻译。

## 5. 主 Composer

选中视频节点后，在节点下方显示宽工作台：

1. 顶部工具行：参考素材缩略图/角色标签、生成模式、运镜入口、上下文调色盘。没有真实数据路径的功能不显示。
2. 中部提示词区：无边框大输入区，中文占位“描述你想生成的视频内容”，支持现有素材引用能力。
3. 底部摘要行：当前模型、`比例 · 清晰度 · 时长 · 数量 · 音频` 摘要、视觉色调、真人验证、预估点数和生成按钮。
4. 打开任一参数、模型或调色面板时关闭其它紧凑浮层；运镜库保持独立模态层。
5. 节点未选中时只显示预览节点，不显示 Composer。

当前数据更新、模型切换校正、草稿 autosave、资产恢复和生成前门禁保持不变。

## 6. 参数面板

参数面板参考确认图六，采用单列分区而不是三个下拉框：

### 6.1 画面比例

以图形卡展示 `自动`、`16:9`、`4:3`、`1:1`、`3:4`、`9:16`、`21:9`。每张卡包含比例轮廓图标和文本；选中态使用亮色描边、勾选标记和更高文字对比度。模型不支持的比例保持可见但禁用，并显示中文原因。

### 6.2 清晰度

使用分段按钮显示 `480P`、`720P`、`1080P`、`4K`。所有档位同时可见，不使用下拉菜单。禁用态显示能力原因。

### 6.3 视频时长

滑杆和秒数输入并排，显示最小、最大刻度。输入失焦或回车时按当前模型的 min/max/step 校正；校正后显示一次中文轻提示。

### 6.4 生成音频

使用“开启 / 关闭”双段控件，标题为“生成音频”。模型不支持时整体禁用，旁边显示问号提示“当前模型不支持生成音频”。

### 6.5 生成数量

使用 `1 个`、`2 个`、`4 个`三段控件。能力不支持的数量禁用，并保留现有 fail-closed 逻辑。

## 7. 运镜库

### 7.1 布局

运镜库使用接近确认图三的视口级模态层：标题“运镜库”、右上角关闭、无英文副标题。第一期保留“全部运镜 / 我的收藏 / 我的运镜”三个中文标签页；搜索框可保留但全部中文，并降低视觉权重。

网格卡只显示预览画面、中文名称和选中标记，不显示内部 ID。底部固定显示当前选择，以及“清除”“使用”按钮。

### 7.2 原创电影感预览

现有抽象圆点/网格素材全部替换。新素材使用统一原创基准场景：

- 统一电影感场景，前景有清晰人物主体，中景有道具，背景有可辨识空间线条；预览素材使用已授权的 DramaClaw 原始 MP4。
- 同一主体、同一环境、同一光照，仅镜头轨迹变化，便于直接比较运镜。
- 每项使用本地 H.264 MP4 预览，由版本 2 manifest 固定稳定 ID、授权来源和播放时长；不依赖 CLI、外部 API 或热链远程媒体。
- 画面应能直观看出固定、跟随、升降、摇镜、平移、推进、拉远、环绕、滚转、FPV、航拍和手持等差异。
- 不使用第三方网站截图、iframe、热链远程媒体或未授权素材。

运镜卡仅在悬停、聚焦或进入可见播放预算时播放，最多四段同时播放；减弱动效模式使用同一 MP4 但不自动播放。

## 8. 调色盘

调色盘改为语义分组圆形色票，参考确认图四：

- 根据已绑定参考动态显示“人物颜色”“场景颜色”“道具颜色”“风格颜色”。没有对应引用的分组不显示。
- 每组提供固定、可访问的高区分度色票；当前选择使用双环和勾选标记，不只依赖颜色表达状态。
- 顶部显示当前角色名称和来源缩略图；没有上下文角色时显示中文空状态。
- 视觉色调独立为“画面色调”区域，使用带实际色彩样本的横向预设：自然、青橙电影、暖色夕阳、冷调月光、黑白。
- 上下文调色只更新 `contextPaletteRefs`，画面色调只更新 `visualTone`，不修改素材本身。

## 9. 可访问性与交互

- 所有可见文本、`aria-label`、tooltip、空状态和错误信息均为中文。
- 模态层打开后聚焦首个控件，Tab/Shift+Tab 不离开模态层；关闭后返回触发按钮。
- 紧凑浮层支持外部点击、Escape 和互斥关闭。
- 选中、禁用、播放、收藏等状态不能只靠颜色，必须有图标或文字辅助。
- 所有控件在 1440x900、1024x768 和 390x844 下不得重叠、溢出或遮挡生成按钮。

## 10. 验收标准

### 10.1 功能验收

- 既有视频参数、模型能力校正、运镜 ID、调色字段、草稿持久化和生成门禁测试保持通过。
- 交互测试覆盖比例卡、分段清晰度、时长、音频、数量、中文运镜库、调色分组和互斥浮层。
- 不引入真实 provider、worker、数据库或计费协议变更。

### 10.2 视觉验收

Playwright 必须输出以下真实界面截图：

1. 桌面视频 Composer 默认状态。
2. 参数面板展开状态。
3. 运镜库展开状态，桌面四列且展示电影感动态预览。
4. 上下文调色盘与画面色调预设。
5. 1024px 窄屏和 390px 移动端布局。

每张截图逐项对照本规格与用户提供的参考图，检查：中文完整性、信息层级、控件形式、卡片比例、对齐、间距、字体、按钮状态、无重叠和下一层内容可见性。只有截图审查通过，才算视觉任务完成。

### 10.3 禁止验收替代

以下结果不能单独证明完成：

- 仅单元测试通过。
- 仅能打开浮层或找到 23 个卡片。
- 仅检查 DOM 文本和控件数量。
- 使用抽象占位动画替代电影感运镜预览。
- 用“功能已实现”解释与参考截图的明显视觉差异。
