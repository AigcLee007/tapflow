# 文本节点全文字号调整设计

## 目标

为画布文本节点增加节点级字号预设。无论文字由用户输入还是大模型生成，只要文字已经显示在节点中，用户点击字号预设后，当前节点内的全部文字都必须立即统一切换字号。

该功能只改变文本节点内容的显示字号，不改变节点宽高、节点位置、画布 viewport 或画布 zoom。

## 用户体验

文本节点被单选并进入编辑状态后，顶部浮动工具栏显示四个字号预设：

| 显示名称 | 持久化值 | 画布节点字号 |
| --- | --- | --- |
| 一号 | `h1` | `18px` |
| 二号 | `h2` | `16px` |
| 三号 | `h3` | `14px` |
| 正文 | `body` | `12px` |

点击任一预设后：

1. 当前节点已有的全部文字立即使用所选字号重新渲染。
2. 文本内容本身保持完全不变，不插入或删除 `#`、`##`、`###` 等 Markdown 标记。
3. 不依赖光标位置或文字选区；即使用户选中了部分文字，字号仍作用于整个节点。
4. 用户后续输入的文字继续使用当前节点字号。
5. 大模型后续生成、覆盖或追加的文字继续使用当前节点字号。
6. 当前字号按钮显示明确的选中状态。

本次功能用节点级预设替换当前工具栏中 H1、H2、H3、Body 的标题格式行为。粗体、斜体、列表和分隔线等其他工具栏能力不在本次范围内。

## 固定节点与内部滚动

字号切换不得改变文本节点的宽度或高度，也不得触发自动扩容。字号增大导致内容超出节点可视区域时，文本内容区域使用垂直内部滚动。

鼠标位于可滚动文本区域时：

- 滚轮滚动节点内文字；
- 不触发画布缩放；
- 不移动节点；
- 滚动到内容边界后也不将同一次滚轮操作传递为画布缩放。

画布其他空白区域仍保持现有缩放行为。

## 数据与持久化

继续使用现有 `FlowNodeData.fontSize` 字段：

```ts
fontSize?: 'h1' | 'h2' | 'h3' | 'body';
```

点击字号预设时只更新节点数据：

```ts
updateNodeData(nodeId, { fontSize: preset });
```

不得通过修改 `text` 来实现字号切换。节点数据沿用现有远程草稿 autosave 链路写入 `flow_drafts.graph_json`，不新增数据库表、API 或浏览器本地权威存储。

兼容规则：

- 旧节点缺少 `fontSize` 时按 `body` 渲染。
- 已保存的 `h1`、`h2`、`h3`、`body` 值继续可读，不需要数据迁移。
- 文本生成结果更新 `text` 时不得覆盖或重置 `fontSize`。
- 字号字段只影响表现，不进入模型 prompt，也不影响工作流输入、计费或生成逻辑。

## 组件边界

### 字号预设定义

在文本节点相关模块中建立单一字号预设映射，画布编辑器、全屏编辑器、按钮标签和测试共用该映射，避免多处三元表达式产生不同字号。

映射至少提供：

- 稳定持久化值；
- 中文显示名称；
- 画布节点字号；
- 全屏编辑字号；
- 默认值 `body`。

全屏编辑器可以使用更适合沉浸阅读的等比例大字号，但四个档位的顺序和当前选中状态必须与画布节点一致。

### 工具栏行为

字号按钮调用独立的节点级字号更新处理器，不进入当前基于 textarea 选区修改 Markdown 的 `applyTextAction` 流程。这样可以保证字号调整与标题、列表、粗体等文本内容变换解耦。

工具栏维持现有紧凑浮层尺寸和视觉语言。标签必须能在按钮内完整显示，并提供悬停提示，例如“全文设为一号字号”。

### 文本渲染

画布 textarea 和全屏 textarea 都从归一化后的节点字号读取样式。切换字号只引发当前文本节点重渲染，不调用 React Flow viewport API，也不调用节点尺寸更新逻辑。

## 非目标

本次不实现：

- 选中文字的局部字号；
- 任意数字字号输入；
- 字号加减步进器；
- 根据内容自动改变节点尺寸；
- 根据画布 zoom 自动补偿字体大小；
- 富文本编辑器迁移；
- Markdown 标题的所见即所得渲染重构。

## 错误与边界处理

- 遇到缺失或未知的 `fontSize` 值时安全回退到 `body`。
- 连续快速切换字号时，以最后一次选择为准，并沿用现有 autosave 防抖机制。
- 空文本节点也可以预先设置字号；之后输入或生成的全文使用该字号。
- 生成进行中切换字号只改变显示样式，不中断生成任务；生成结果返回后继续保留所选字号。
- 远程草稿发生现有 revision 冲突时，仍使用当前统一冲突处理，不为字号引入旁路保存。

## 测试与验收

至少增加以下聚焦回归测试：

1. 已有文字的节点点击“一号”后，全文立即显示为 `18px`，节点 `text` 内容逐字不变。
2. 即使 textarea 中存在选区，点击字号仍更新节点级 `fontSize`，不插入 Markdown 标记。
3. 四个按钮分别写入正确的 `h1`、`h2`、`h3`、`body` 值，并正确显示选中态。
4. 缺少 `fontSize` 的旧节点按正文 `12px` 渲染。
5. 切换字号前后节点宽高、位置和画布 viewport 不变。
6. 内容溢出时文本区域可垂直滚动，滚轮事件不触发画布 zoom。
7. 大模型结果更新 `text` 后保留节点原有 `fontSize`。
8. 草稿保存并重新加载后恢复相同字号。
9. 全屏编辑器与画布节点使用相同档位和选中状态。

实现完成后运行文本节点聚焦测试与 `npm run build`。如果 UI 行为发生变化，还应在真实浏览器中验证普通画布缩放、节点内部滚动和刷新恢复三个流程。

## 验收标准

功能满足以下条件即视为完成：

- 用户可对已有文字一键调整整个文本节点的字号；
- 点击字号不会修改任何文本字符；
- 节点宽高与画布 zoom 不受影响；
- 溢出内容可在节点内部滚动查看；
- 字号在用户输入、模型生成和刷新后保持；
- 旧草稿无需迁移即可正常显示；
- 聚焦测试和项目构建通过，或基础设施导致的失败有准确记录。
